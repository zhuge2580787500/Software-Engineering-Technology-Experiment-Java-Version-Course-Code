# 银行业务模拟程序

## 项目概述

本项目是《软件工程技术》第二讲实践任务 2.1 的实现，模拟了一个简化的银行账户系统。项目严格按照面向对象设计原则构建，使用 Maven 管理依赖，使用 JUnit 5 编写了全面的单元测试用例，并充分利用了 Java 8+ 的新特性。

## 技术栈

| 技术 | 版本/说明 |
|------|-----------|
| Java | 17 (兼容 Java 8+) |
| Maven | 标准 Maven 项目结构 |
| JUnit | 5.10.2 |

## 类设计

### `BankAccount` — 银行账户类

- **私有属性**：`accountId`（账号）、`balance`（余额）、`interestRate`（年利率）
- **构造方法**：无参构造（默认余额0，利率1%）和带参构造（支持自定义，含参数校验）
- **业务方法**：
  - `getBalance()` / `getInterestRate()` / `getAccountId()` — 查询
  - `setInterestRate(double rate)` — 设置利率（校验非负）
  - `deposit(double amount)` — 存款（校验金额>0）
  - `withdraw(double amount)` — 取款（校验金额>0且不超过余额）
  - `calculateInterest()` — 计算并结算利息（进阶功能）
  - `printAccountInfo()` — 打印账户信息

### `UseAccount` — 主测试类

包含 `main()` 方法，模拟完整业务流程：开户 → 存款（合法/非法）→ 取款（合法/超额）→ 利率查询与修改 → 最终确认。

## Java 8+ 特性应用

| 特性 | 应用场景 |
|------|----------|
| Lambda 表达式 | `DoublePredicate` 验证存款金额有效性 |
| Stream API | 批量存款/取款、多账户余额汇总、利率筛选 |
| `IntStream` | 批量创建测试账户、账户状态一致性验证 |
| `Arrays.stream()` | 数组转 Stream 进行聚合计算 |
| `BigDecimal` | 金额精确计算，避免浮点精度问题 |
| `method reference` | `BankAccount::getBalance`、`BankAccount::getAccountId` |
| `Predicate` 函数式接口 | 高利率账户筛选逻辑 |

## 构建与运行

### 编译
```bash
mvn compile
```

### 运行主程序
```bash
mvn exec:java -Dexec.mainClass=banking.UseAccount
```

### 运行测试
```bash
mvn test
```

### 打包
```bash
mvn package
```
