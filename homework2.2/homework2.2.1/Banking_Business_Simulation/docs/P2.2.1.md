# 第二讲实践任务2.1：银行业务模拟程序

## 🎯 实验目的
1. 掌握Java中**类与对象**的定义和使用。
2. 理解并应用**封装（Encapsulation）**原则（如私有属性与公共方法）。
3. 掌握**构造方法**的重载与使用。
4. 培养在业务方法中加入**数据合法性校验**（如防止取款透支）的编程习惯。

---

## 📝 实验要求

本程序需要设计两个类：银行账户类 `BankAccount` 和 主测试类 `UseAccount`。

### 1. 银行账户类：`BankAccount`

该类是对现实世界中银行账户的抽象，需严格遵循面向对象的封装原则。

#### 1.1 数据属性（成员变量）
所有属性必须声明为 `private`（私有），以保证数据的安全性：
*   `accountId` (`String` 类型)：账号（*教学补充属性，便于区分不同账户*）
*   `balance` (`double` 类型)：账户余额
*   `interestRate` (`double` 类型)：年利率（例如 `0.03` 代表 `3%`）

#### 1.2 构造方法（Constructors）
*   **无参构造方法**：提供一个默认构造方法，将余额设为0，利率设为0.01。
*   **带参构造方法**：接收账号、初始余额和初始利率，并在创建对象时完成初始化。*（需注意初始余额不能为负数）*

#### 1.3 操作行为（成员方法）
提供以下 `public` 方法，并在特定方法中加入业务逻辑判断：

| 方法名称 | 参数 | 返回值 | 功能描述与逻辑要求 |
| :--- | :--- | :--- | :--- |
| `getBalance()` | 无 | `double` | **查询余额**：返回当前账户的余额。 |
| `getInterestRate()` | 无 | `double` | **查询利率**：返回当前账户的利率。 |
| `setInterestRate(...)` | `double rate` | `void` | **设置利率**：修改当前账户的利率。*（需校验：利率不能为负数）* |
| `deposit(...)` | `double amount` | `void` | **存款**：将指定金额加到余额中。<br>*(需校验：存款金额必须 > 0，否则提示“存款失败：金额必须大于0”)* |
| `withdraw(...)` | `double amount` | `void` | **取款**：从余额中扣除指定金额。<br>*(需校验：1. 取款金额必须 > 0；2. 取款金额不能大于当前余额，若大于则提示“取款失败：余额不足”)* |
| `printAccountInfo()`| 无 | `void` | **打印账户信息**：在控制台输出当前账号、余额及利率信息。 |

---

### 2. 主测试类：`UseAccount`

该类包含程序的入口 `main()` 方法，用于模拟用户的真实银行操作流程。

#### `main()` 方法执行流程要求：
请在 `main` 方法中严格按以下步骤编写测试代码，以验证 `BankAccount` 类的正确性：

1. **开户（创建对象）**：使用带参构造方法创建一个 `BankAccount` 对象（例如：账号 "VIP666"，初始余额 `1000.0`，利率 `0.02`）。
2. **状态展示**：调用方法打印该账户的初始信息。
3. **存款测试**：
    * 存入合法金额（如 `500.0`），打印存款成功信息及当前余额。
    * 存入非法金额（如 `-100.0`），触发错误提示。
4. **取款测试**：
    * 取出合法金额（如 `200.0`），打印取款成功信息及当前余额。
    * 取出超额金额（如 `5000.0`），触发“余额不足”的错误提示。
5. **利率测试**：
    * 查询并打印当前利率。
    * 调用方法将利率修改为 `0.035`。
6. **最终确认**：再次调用打印账户信息的方法，确认所有修改均已生效。

## 🌟 进阶挑战（选做）
学有余力的同学可以尝试在原基础上增加以下功能：
1. **利息结算方法 `calculateInterest()`**：根据当前余额和利率计算利息，并将利息直接存入余额中。
2. **静态变量应用**：思考如果所有银行账户的利率都是统一规定的，如何使用 `static` 关键字来修饰 `interestRate` 属性，并修改相关的方法。
3. **格式化输出**：使用 `String.format()` 或 `System.out.printf()` 让金额始终保留两位小数（如 `1000.00`）。
