# Vibe Coding 项目规范 Prompt：Java 命令行日志关键词分析工具

## 1. 项目概述
请严格按照以下规范实现一个 **Java 命令行日志关键词分析工具**。该工具用于从日志文件中提取包含指定关键词的行，并输出统计信息。

## 2. 技术栈与运行环境
- **语言**：Java 17（必须使用标准库，禁止引入第三方依赖）
- **构建工具**：Maven（标准目录结构，`pom.xml` 最小化配置）
- **打包方式**：生成可执行 JAR（`mvn clean package`，主类通过 `Main-Class` 指定）
- **运行方式**：`java -jar log-analyzer.jar [参数]`（所有参数必须通过命令行传入）

## 3. 功能需求（必须全部实现）
### 3.1 参数解析
支持以下命令行参数：
| 参数 | 全称 | 是否必需 | 说明 | 默认值 |
|------|------|----------|------|--------|
| `-f` | `--file` | 是 | 指定日志文件路径 | 无 |
| `-k` | `--keyword` | 是 | 关键词（支持多个，用逗号分隔） | 无 |
| `-i` | `--ignore-case` | 否 | 匹配时忽略大小写 | false |
| `-c` | `--count` | 否 | 只输出匹配行数，不输出具体行 | false |
| `-o` | `--output` | 否 | 将结果输出到指定文件（不指定则打印到控制台） | 标准输出 |
| `-h` | `--help` | 否 | 打印帮助信息并退出 | - |

**规则**：
- 参数解析必须健壮：未知参数、缺少必需参数、文件不存在等情况要有明确错误提示。
- 支持 `-f=value` 和 `-f value` 两种写法。
- `--keyword` 支持多个关键词，如 `--keyword ERROR,WARN`，多个关键词之间为 **或** 关系。
- 如果同时使用 `-h`，忽略其他参数直接打印帮助并退出。

### 3.2 日志读取
- 必须支持 **大文件流式读取**（使用 `BufferedReader`，禁止一次性读取整个文件到内存）。
- 编码统一为 **UTF-8**。
- 读取过程中出现 IO 异常必须捕获并给出清晰错误信息，然后以非零状态码退出。

### 3.3 关键词匹配
- 支持**子串匹配**（包含即命中），非正则表达式或单词匹配。
- 若指定 `-i`，则匹配忽略大小写；否则严格区分大小写。
- 支持多个关键词，只要包含任意一个即命中。
- 匹配结果保留原行内容（不改变大小写）。

### 3.4 输出格式
- 默认模式：每行输出格式为 `行号: 原始日志内容`（行号从 1 开始）。
- 若指定 `-c`：输出一个整数（匹配总行数），不输出具体行。
- 输出到文件时，文件编码为 UTF-8；若文件已存在则覆盖。
- 控制台输出时，结果前后不要有多余空行；错误信息输出到 `System.err`。

## 4. 代码结构规范
- 包名：`com.loganalyzer`。
- 类结构：
    - `Main`：入口类，负责参数解析、调用核心逻辑。
    - `LogAnalyzer`：核心分析类，负责读取、匹配、输出。
    - `CliOptions`：参数解析结果封装类（不可变对象）。
    - 如果需要其他工具类，请自行设计，但必须保持高内聚低耦合。
- 所有类和方法必须有 Javadoc 注释（至少包含功能说明、参数说明、返回值说明）。
- 方法长度不超过 50 行，复杂逻辑必须拆分。
- 禁止使用 `System.exit()` 在业务逻辑中退出，统一在 `Main` 中通过返回值控制退出码（0 成功，非 0 失败）。

## 5. 错误处理与退出码
| 场景                                   | 退出码 | 错误信息（示例）                                                           |
|----------------------------------------|--------|----------------------------------------------------------------------------|
| 参数解析失败（未知参数、缺少必需参数） | 1      | `Error: Unknown option '--xyz'` 或 `Error: Missing required option --file` |
| 文件不存在                             | 2      | `Error: Log file not found: /path/to/file.log`                             |
| 文件读取失败（权限、IO 异常）          | 3      | `Error: Failed to read file: <具体异常消息>`                               |
| 输出文件无法创建或写入                 | 4      | `Error: Failed to write output file: <具体异常消息>`                       |
| 其他未预期异常                         | 5      | `Unexpected error: <异常堆栈前 3 行>`                                      |

所有错误信息以 `Error: ` 开头，写入 `System.err`。
