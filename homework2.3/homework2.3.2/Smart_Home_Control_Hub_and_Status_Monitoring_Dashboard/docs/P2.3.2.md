# 第二讲实践任务3.2：智能家居控制中枢与状态监控看板
**📍 考察模式：命令模式 (Command) + 观察者模式 (Observer)**

**背景描述：**
你正在开发一款智能家居的手机App控制端。App界面上有各种按钮，点击按钮会向家里的智能电器（电灯、空调）发送指令。同时，App首页有一个“家庭状态看板”，只要任何电器的状态发生改变，看板必须立刻自动更新显示最新状态。

**具体要求：**
1. **底层接收者 (Receiver)**：创建 `Light`（电灯）和 `AirConditioner`（空调）类，包含开、关、调节等具体执行方法，并在状态改变时触发通知。
2. **应用命令模式**：
    * 设计接口 `Command`，包含 `execute()` 方法。
    * 实现具体命令类：如 `LightOnCommand`、`LightOffCommand`、`ACSetTemperatureCommand`，这些命令内部持有对具体电器（Receiver）的引用。
    * 设计调用者 `SmartAppController`（类似遥控器），拥有多个插槽（数组或Map），可以绑定不同的命令对象，并提供 `buttonWasPressed(int slot)` 方法来触发命令。
3. **应用观察者模式**：
    * 电器类（如 `Light`）需扮演被观察者（Subject），包含添加、移除和通知观察者的方法。
    * 设计观察者接口 `DeviceObserver`，包含 `update(String message)` 方法。
    * 实现具体观察者 `HomeDashboard`（状态看板），当收到电器状态变化的通知时，在控制台打印“【看板更新】XXX设备状态已变为YYY”。

**测试流程：**
在 `Main` 方法中，实例化电器；将看板注册为电器的观察者；实例化命令并绑定到 App 控制器的按钮上；模拟按下控制器按钮，观察是否既执行了命令，又自动触发了看板的更新。
